# 纳米孔电流轨迹分段 · 基线补偿复核台

纯浏览器运行的 TypeScript + React 单页应用：对纳米孔电流轨迹做**分段（驻留约束）+ 每段整数基线补偿**的两级优化复核。无后端、无在线服务调用，页面加载后所有计算都在浏览器本地完成；发布物为 nginx 托管的静态文件，附带 `/healthz` 健康检查。

## 模型与优化目标

给定：

- 6–600 个整数电流样本，3–80 个有序唯一符号及其整数目标电平；
- 统一驻留区间 `[L, U]`：每段样本数（驻留长度）∈ [L, U]；
- 最大补偿 `D` ∈ 0..8，每段补偿 `cᵢ ∈ [-D, D]` 为整数；
- **首个补偿固定为零**：`c₀ = 0`；**相邻补偿之差不超过 1**：`|cᵢ − cᵢ₋₁| ≤ 1`；
- 段内误差按生效电平（目标电平 + 补偿）计算：`eᵢ = Σ |sampleₓ − (tᵢ + cᵢ)|`。

依次优化（后者仅在前者同优时起决定作用）：

1. **总绝对误差最小** `E = Σ eᵢ`；
2. **补偿变化总量最小** `V = |c₀| + Σ|cᵢ − cᵢ₋₁| = Σ|cᵢ − cᵢ₋₁|`（c₀=0）；
3. 在全部两级同优方案中，取交错向量 `(e₀, c₀, e₁, c₁, …)` 的**字典序最小**解作为规范路径（`eᵢ` 为第 i 段结束下标，末段 `eₖ₋₁ = n−1`）。

同时列出**全部两级同优方案**在每个边界（结束下标）与每个补偿上的**完整可达集合**：状态 `(i, p, c)` 可达当且仅当存在一条经过它的方案同时达到 `E*` 与 `V*`（由前向 DP 最优值 + 反向 DP 最优值闭合判定）。

### 算法

- 前向 DP `F[i][p][c]` / 反向 DP `B[i][p][c]` 均以 `(误差, 变化量)` 字典序为值；
- 段误差用前缀和 O(1) 求；每个目标补偿的三个合法前驱补偿各用一个**滑动窗口单调队列**，整体约 `O(k · n · (2D+1))`；
- 可达判定 `F[i][p][c] + B[i][p][c] = (E*, V*)`；
- 规范路径按交错向量贪心：每段先取最小可达结束下标，同下标下取最小可达补偿，并用后缀代价保证可续接。
- 单元测试以**暴力枚举**（枚举全部驻留组合 × 全部合法补偿序列）为参照，随机用例逐一比对最优值、规范向量、全部可达结束/补偿/状态集合。

## 页面行为

- 左侧录入区（草稿自动保存在浏览器 `localStorage`）：样本、符号、目标电平、驻留上下限、D；
- 右侧联动显示：规范路径（交错向量、分段表：区间/驻留/补偿/生效电平/段误差）、每段补偿与边界的完整同优可达集合、SVG 轨迹图（实测轨迹、规范电平台阶、全部可达边界刻度、选中段的可达 `(结束,补偿)` 状态 ◆）；
- **非法输入或无解时保留草稿**，顶部横幅给出中文首因，“定位到首因字段”滚动并聚焦第一个出错字段；无解时区分原因代码（首段/中段/末段无法落位）。

## 本地开发

```bash
npm install --cache .npm-cache   # 如全局 npm 缓存目录不可写
npm test          # 单元测试（vitest）
npm run build     # tsc 类型检查 + vite 静态产物构建到 dist/
npm run dev       # 本地开发服务器
```

## Docker 发布

宿主机端口通过 `WEB_PORT` 配置（默认 8080）：

```bash
cp .env.example .env      # 按需修改 WEB_PORT
docker compose up -d --build
curl http://localhost:8080/healthz      # -> ok
```

### 一次性验收服务 verify

```bash
docker compose build
docker compose run --rm verify
```

`verify` 服务（构建目标为 `builder` 阶段）依次执行：

1. `npm test`：单元测试；
2. `npm run build`：类型检查与生产构建；
3. `scripts/smoke.sh`：等待 `web` 健康后做 HTTP 冒烟（`/healthz` 返回 `ok`、首页含挂载点、其引用的 JS 产物可下载）。

它是一次性任务（`restart: "no"`），全部通过退出码 0，任一失败以非零退出码自行退出，可用 `$?` / CI 获取结果。
